# Projeto 1 · Detecção de pessoas sob oclusão parcial

Material em preparação.

O projeto utilizará o dataset POP, com imagens aéreas térmicas de pessoas em ambientes naturais. A investigação tratará dos efeitos da oclusão parcial, da escala dos alvos e das decisões de avaliação sobre o desempenho de um detector.

Referência do dataset: [Song et al. (2025), An infrared dataset for partially occluded person detection in complex environment for search and rescue](https://doi.org/10.1038/s41597-025-04600-0).
